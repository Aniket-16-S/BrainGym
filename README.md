# Brain Candy Index

A static, front-end-only interactive index of free websites and apps for training and expanding your brain, inspired by the *Brain Candy* Shorts by AveyTv.


## Add or edit sites
Edit `js/data.js`. Each row is `[name, url, category, blurb, "tags", bonus, androidAppUrl]`.
Categories: `brain`, `logic`, `shield`, `data`, `make`, `wonder` (colours and names are defined at the top of the file).

## Notes
- Icons come from Google's favicon service; if one fails to load, the site shows coloured initials instead.
- Light/dark follows the system setting and can be toggled (remembered in localStorage).
- Please re-check links and pricing occasionally; free tiers change.
